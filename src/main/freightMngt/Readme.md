# Freight Management

This package contains classes and functionality related to freight management operations.

## Overview

Freight management includes operations such as:
- Train configuration
- Dispatch management
- Freight loading and unloading
- Route planning

## Key Components

- **DispatchController**: Manages train dispatch operations
- **TravelTimeController**: Handles travel time calculations
- **WagonsUnloadingController**: Manages wagon unloading operations
