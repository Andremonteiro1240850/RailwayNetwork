# SQL Scripts

This folder contains all SQL scripts used to create, populate, and maintain the project's database.

## Folder Structure


**schema.sql** - Defines the database schema (tables, relationships, constraints)  
**initial_data.sql** - Inserts initial seed data into the database  
**USBD8.sql** - Script for user story 8 (List of all locomotives of a given type.)  
**USBD13.sql** - Script for user story 13 ( List of all locomotives of a given type and gauge that belong to a given operator).  
**USBD15.sql** - Script for user story 15 ( How many lines depart from a given endpoint.)  
**USBD19.sql** - Script for user story 19 ( Number of segments of a given owner, by track type.)
