# Railway Logistics Management System
## Glossary (BDDAD – Final Version)

### Terms, Expressions and Acronyms (TEA)

| TEA (EN) | TEA (PT) | Description (EN) |
|---------|----------|------------------|
| Acceleration | Aceleração | Acceleration capability of a locomotive model, used in operational performance calculations. |
| Boxcar | Vagão Coberto | Freight wagon designed for transporting general goods protected from weather conditions. |
| Building | Edifício | Physical structure within a facility used for storage or cargo handling operations. |
| Building Type | Tipo de Edifício | Classification of a building according to its operational purpose (e.g. warehouse, grain silo, refrigerated area). |
| Composite Route | Rota Composta | Route composed of multiple freights transported sequentially by the same train. |
| Container | Contentor | Standard intermodal transport unit (20ft, 40ft, 45ft). |
| Departure Time | Hora de Partida | Timestamp when a train leaves a facility. |
| Destination Facility | Instalação de Destino | Facility where a freight transportation ends and wagons are unloaded. |
| Double Track | Via Dupla | Railway line configuration with two parallel tracks allowing bidirectional circulation. |
| Endpoint | Ponto Final | Facility that represents the start or end of a railway line or route. |
| Facility | Instalação Ferroviária | Railway operational point such as a station, terminal, or freight yard. |
| Facility Type | Tipo de Instalação | Classification of a facility based on its operational role. |
| Freight | Carga / Mercadoria | Set of wagons that must be transported from an origin facility to a destination facility. |
| Freight Train | Comboio de Mercadorias | Train composed of locomotives and wagons assigned to transport freight. |
| Freight Yard | Pátio de Mercadorias | Area within a facility used for parking, sorting, and assembling wagons. |
| Frequency | Frequência | Electric supply frequency required by an electric locomotive, measured in Hertz. |
| Gauge | Bitola | Distance between rails that determines rolling stock compatibility. |
| Grain Silo | Silo de Cereais | Storage structure designed for bulk grain commodities. |
| Grain Wagon | Vagão de Cereais | Wagon designed for transporting grain and similar bulk goods. |
| Infrastructure Owner | Proprietário da Infraestrutura | Entity responsible for maintaining and managing railway lines and their segments. |
| Line Segment | Segmento de Linha | Portion of a railway line with defined physical and operational characteristics. |
| Locomotive | Locomotiva | Powered railway vehicle used to pull freight trains. |
| Locomotive Model | Modelo de Locomotiva | Technical specification defining characteristics shared by a family of locomotives. |
| Maximum Weight per Meter | Peso Máximo por Metro | Maximum load supported by a railway segment, measured in kg/m. |
| Origin Facility | Instalação de Origem | Facility where freight loading begins. |
| Path | Caminho / Trajeto | Ordered list of stations that a train must pass through to accomplish a route. |
| Payload | Carga Útil | Maximum weight of goods that a wagon can transport. |
| Planned Train | Comboio Planeado | Train defined with route and scheduled departure time. |
| Power | Potência | Engine power of a locomotive model, measured in kilowatts (kW). |
| Railway Infrastructure | Infraestrutura Ferroviária | Physical railway system including tracks, lines, and facilities. |
| Railway Line | Linha Ferroviária | Continuous railway connection composed of one or more line segments. |
| Refrigerated Area | Área Refrigerada | Temperature-controlled storage area for perishable goods. |
| Rolling Stock | Material Circulante | Railway vehicles including locomotives and wagons. |
| Route | Rota | Transportation plan describing freights and the path taken by a train. |
| Scheduled Departure Time | Hora de Partida Programada | Planned date and time for a train to depart from its origin facility. |
| Segment Length | Comprimento do Segmento | Physical length of a railway line segment. |
| Siding | Desvio / Via de Cruzamento | Auxiliary track that allows trains to cross or overtake on single-track lines. |
| Simple Route | Rota Simples | Route involving a single freight transportation. |
| Single Track | Via Simples | Railway line configuration with a single track. |
| Speed Limit | Limite de Velocidade | Maximum permitted speed on a railway line segment. |
| Station | Estação | Railway facility where trains may stop or pass. |
| Tank Car | Vagão-Cisterna | Wagon designed for transporting liquids or gases. |
| Terminal | Terminal Ferroviário | Facility dedicated to loading, unloading, and assembling freight trains. |
| Track Type | Tipo de Via | Classification of a railway segment as single or double track. |
| Train | Comboio | Operational unit composed of locomotives and wagons assigned to a route. |
| Train Movement | Movimento do Comboio | Record of a train crossing or stopping at a facility with timestamps. |
| Train Route | Percurso do Comboio | Ordered list of facilities visited by a train, including arrival and departure times. |
| Voltage | Voltagem | Electric supply voltage required by an electric locomotive, measured in volts. |
| Wagon (Freight Car) | Vagão de Carga | Non-powered rail vehicle used to transport freight. |
| Warehouse | Armazém | Storage building used for handling and storing freight goods. |
