# Railway Logistics Management System - Glossary (BDDAD Focus)

## Terms, Expressions and Acronyms (TEA)

| **_TEA_ (EN)**                         | **_TEA_ (PT)**                         | **_Description_ (EN)**                                                                 |
|----------------------------------------|----------------------------------------|----------------------------------------------------------------------------------------|
| Railway Infrastructure                 | Infraestrutura Ferroviária            | Physical rail system supporting freight transportation, including tracks and facilities.|
| Railway Line                            | Linha Ferroviária                      | Continuous rail connection between facilities, composed of multiple line segments.      |
| Line Segment                            | Segmento de Linha                     | Section of a railway line with defined characteristics such as length, gauge, and speed limit.|
| Single Track                            | Via Simples                           | Track configuration with only one track, requiring sidings for train crossings.         |
| Double Track                            | Via Dupla                             | Track configuration with two tracks allowing bidirectional flow without interruption.   |
| Electrified Segment                     | Segmento Eletrificado                 | Line segment equipped with overhead electrical systems for electric locomotive operation.|
| Gauge                                   | Bitola                                | Distance between the inner sides of the rails determining compatibility with vehicles.  |
| Endpoint                                | Ponto Final                           | Terminal facility where a railway line begins or ends.                                  |
| Siding                                  | Desvio / Via de Cruzamento            | Track area that allows trains to pass each other on single-track routes.                |
| Station                                 | Estação                               | Operational node where train movement, control and coordination occurs.                 |
| Terminal                                | Terminal Ferroviário                  | Major freight handling installation for loading, unloading and assembling trains.       |
| Freight Yard                            | Pátio de Mercadorias                  | Area for sorting, parking and assembling wagons within a station or terminal.          |
| Infrastructure Owner                    | Proprietário da Infraestrutura        | Entity responsible for maintaining and managing railway lines and their segments.       |
| Train Operating Company / Railway Operator | Operador Ferroviário               | Company owning rolling stock and providing railway freight services.                    |
| Rolling Stock                           | Material Circulante                   | All railway vehicles including locomotives and wagons.                                  |
| Locomotive                              | Locomotiva                            | Powered vehicle providing traction to pull freight trains.                               |
| Diesel Locomotive                       | Locomotiva Diesel                     | Locomotive powered by internal fuel combustion.                                          |
| Electric Locomotive                     | Locomotiva Elétrica                   | Locomotive powered by electricity supplied via electrified segments.                     |
| Locomotive Model                        | Modelo de Locomotiva                  | Technical specification shared by a family of locomotives (power, dimensions, speed).    |
| Wagon (Freight Car)                     | Vagão de Carga                        | Non-powered rail vehicle used to transport goods.                                        |
| Wagon Model                             | Modelo de Vagão                       | Technical specification describing wagon capacity, dimensions, and configuration.       |
| Container                               | Contentor                             | Standard freight transport unit used in intermodal operations (e.g., 20ft/40ft).        |
| Tare                                    | Tara                                  | Empty weight of a wagon used to calculate allowable payload.                             |
| Freight (Service)                       | Serviço de Carga / Comboio de Carga   | Movement of a set of wagons between origin and destination facilities.                   |
| Path                                    | Caminho                               | Ordered sequence of stations a train must follow between endpoints.                      |
| Route                                   | Rota                                  | Defined plan describing the ordered facilities included in a freight movement.           |
