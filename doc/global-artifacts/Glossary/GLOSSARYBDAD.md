# Railway Logistics Management System - Glossary (BDDAD Focus)

## Terms, Expressions and Acronyms (TEA)

| **_TEA_ (EN)**                           | **_TEA_ (PT)**                           | **_Description_ (EN)**                                                                 |
|------------------------------------------|------------------------------------------|----------------------------------------------------------------------------------------|
| Railway Infrastructure                   | Infraestrutura Ferroviária              | Physical rail system supporting freight transportation, including tracks and facilities.|
| Railway Line                              | Linha Ferroviária                        | Continuous rail connection between facilities, composed of one or multiple line segments.|
| Line Segment                              | Segmento de Linha                       | Section of a railway line with defined characteristics such as length, gauge, speed limit, and track type. |
| Track Type                                | Tipo de Via                             | Classification of a segment as single or double track, determining how trains circulate. |
| Single Track                              | Via Simples                             | Track configuration with only one rail track, requiring sidings for train crossings.    |
| Double Track                              | Via Dupla                               | Track configuration with two parallel tracks allowing simultaneous bidirectional flow.   |
| Electrified Segment                       | Segmento Eletrificado                   | Line segment equipped with overhead electrical systems for electric locomotive operation.|
| Gauge                                     | Bitola                                  | Distance between inner sides of the rails, determining vehicle compatibility.           |
| Endpoint                                  | Ponto Final                             | Terminal facility where a railway line begins or ends.                                 |
| Siding                                    | Desvio / Via de Cruzamento              | Auxiliary track that allows trains to cross or overtake on single-track routes.         |
| Station                                   | Estação                                 | Operational rail facility where trains stop or pass.                                    |
| Terminal                                  | Terminal Ferroviário                    | Freight-handling facility for loading, unloading, sorting, and assembling trains.       |
| Freight Yard                              | Pátio de Mercadorias                    | Area within a facility for parking, sorting, and assembling wagons.                     |
| Infrastructure Owner                      | Proprietário da Infraestrutura          | Entity responsible for maintaining and managing railway lines and segments.             |
| Train Operating Company / Railway Operator | Operador Ferroviário                 | Company owning locomotives and wagons and providing freight services.                   |
| Rolling Stock                             | Material Circulante                     | All railway vehicles, including locomotives and wagons.                                 |
| Locomotive                                | Locomotiva                              | Powered rail vehicle providing traction to pull freight trains.                         |
| Diesel Locomotive                         | Locomotiva Diesel                       | Locomotive powered by internal fuel combustion.                                         |
| Electric Locomotive                       | Locomotiva Elétrica                     | Locomotive powered by electricity supplied through electrified segments.                |
| Locomotive Model                          | Modelo de Locomotiva                    | Technical specification shared by a family of locomotives (power, weight, dimensions).  |
| Wagon (Freight Car)                       | Vagão de Carga                          | Non-powered rail vehicle used to transport freight.                                     |
| Wagon Model                               | Modelo de Vagão                         | Technical specification describing wagon capacity, dimensions, configuration, and gauge.|
| Wagon Type                                 | Tipo de Vagão                           | Category of wagon based on transported goods (e.g., grain hopper, tank car, flatcar).   |
| Multi-Gauge Support                        | Suporte Multi-Bitola                     | Capability of rolling stock to operate on more than one gauge type.                     |
| Container                                 | Contentor                               | Standard intermodal transport unit (20ft, 40ft, 45ft).                                  |
| Tare                                      | Tara                                    | Empty weight of a wagon, used to calculate payload capacity.                            |
| Freight (Service)                         | Serviço de Carga / Comboio de Carga     | Transport of a set of wagons between origin and destination facilities.                 |
| Path                                      | Caminho                                 | Ordered sequence of facilities a train must follow between endpoints.                   |
| Route                                     | Rota                                    | Defined plan describing the ordered facilities included in a freight movement.           |
