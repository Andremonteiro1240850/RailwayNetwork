# Railway Logistics Management System - Business Glossary

## Terms, Expressions and Acronyms (TEA)

| **_TEA_** (EN) | **_TEA_** (PT) | **_Description_** (EN) |
|:---------------|:---------------|:----------------------|
| **Aisle** | **Corredor** | Passageway between rows of storage bays in warehouse for movement and access. |
| **Allocation** | **Alocação** | Process of assigning specific quantities from inventory boxes to fulfill order lines. |
| **Assembly** | **Montagem** | Process of coupling locomotives and wagons to form complete trains. |
| **Bay** | **Área de Armazenamento** | Specific storage location within warehouse identified by coordinates. |
| **Bogies** | **Bogies** | Chassis framework carrying wheelset under railway vehicles for weight distribution. |
| **Box** | **Caixa** | Minimum storage unit containing specific SKU quantity with unique identifier. |
| **Boxcar** | **Vagão Coberto** | Enclosed wagon type for general goods protection. |
| **Capacity** | **Capacidade** | Maximum weight limit for trolleys or storage limit for bays. |
| **Cargo** | **Carga** | Goods or commodities transported by railway including raw materials and products. |
| **Cargo Flow** | **Fluxo de Carga** | Movement pattern of cargo through terminals, freight yards, and routes. |
| **Chemical Tank Car** | **Vagão-tanque Químico** | Specialized tank wagon for chemicals with purity specifications. |
| **Circulation Lines** | **Linhas de Circulação** | Terminal tracks for wagon movement between areas. |
| **Complex Route** | **Rota Complexa** | Route that allows transportation of multiple freights together. |
| **Container** | **Contentor** | Standardized cargo unit (20ft, 40ft, 45ft) for intermodal transport. |
| **Cycle Count** | **Contagem Cíclica** | Return reason for inventory audit discrepancies requiring inspection. |
| **Customer Remorse** | **Arrependimento do Cliente** | Return reason where undamaged products can be restocked. |
| **Damaged** | **Danificado** | Return reason for broken products requiring disposal. |
| **Dispatch** | **Expedição** | Operation removing products from storage following FEFO/FIFO rules. |
| **Dispatching** | **Despacho** | Planning train movements to avoid delays and maximize efficiency. |
| **Double Track** | **Via Dupla** | Railway segment with parallel tracks allowing bidirectional movement. |
| **Electrified Line** | **Linha Eletrificada** | Track segment with overhead electrical systems for electric locomotives. |
| **Endpoint** | **Ponto Final** | Terminal facility where railway lines begin or end. |
| **Expired** | **Expirado** | Return reason for products past expiry date requiring disposal. |
| **Expiry Date** | **Data de Validade** | Date after which perishable products become unsuitable. |
| **FEFO (First-Expired-First-Out)** | **FEFO** | Inventory rule dispatching nearest-expiry products first. |
| **FIFO (First-In-First-Out)** | **FIFO** | Inventory rule dispatching oldest products by receipt date. |
| **Flatcar** | **Vagão Plataforma** | Open wagon for containers, vehicles, and machinery. |
| **Freight** | **Carga** | Goods or commodities being transported by rail. |
| **Freight Car** | **Vagão de Carga** | Railway vehicle designed for transporting goods. |
| **Freight Manager** | **Gestor de Carga** | User profile overseeing cargo operations and planning. |
| **Freight Service Plan** | **Plano de Serviço de Carga** | Detailed planned sequence of operations and passage times for a freight movement. |
| **Freight Yard** | **Pátio de Carga** | Railway facility for loading, unloading, and train assembly. |
| **Gauge** | **Bitola** | Distance between inner rail sides affecting vehicle compatibility. |
| **Hopper Car** | **Vagão Graneleiro** | Wagon for bulk materials like coal and grains with bottom discharge. |
| **Infrastructure Owner** | **Proprietário de Infraestrutura** | Entity responsible for railway line maintenance. |
| **Intermodal Transport** | **Transporte Intermodal** | Combining rail with trucks/ships for door-to-door logistics. |
| **Intermodal Terminal** | **Terminal Intermodal** | Facility transferring containers between transport modes. |
| **Inventory Replenishment** | **Reabastecimento de Inventário** | Unloading wagons and storing products following FEFO/FIFO. |
| **Line Segment** | **Segmento de Linha** | Individual track section with specific technical characteristics. |
| **Loading Operation** | **Operação de Carregamento** | Process of placing cargo into wagons at terminals. |
| **Locomotive** | **Locomotiva** | Powered rail vehicle providing traction for trains. |
| **Logistical Operator** | **Operador Logístico** | Company managing freight transportation operations. |
| **Mineral Oil Car** | **Vagão de Óleo Mineral** | Tank wagon for petrochemicals and mineral oils. |
| **Operational Time Window** | **Janela Operacional** | Defined time interval during which operations or train movements must occur. |
| **Order** | **Pedido** | Customer request for products with quantities and dates. |
| **Order Line** | **Linha de Pedido** | Individual order item specifying SKU and quantity. |
| **Parking Lines** | **Linhas de Estacionamento** | Terminal sidings for temporary wagon storage. |
| **Path** | **Caminho** | Ordered list of facilities through which a train must pass. |
| **Perishable Goods** | **Bens Perecíveis** | Products requiring expiry date tracking and FEFO management. |
| **Planner** | **Planeador** | User profile analyzing and adjusting train schedules. |
| **Pressure Gas Car** | **Vagão de Gás sob Pressão** | Tank wagon for liquefied gases requiring pressure. |
| **Quarantine** | **Quarentena** | Controlled area inspecting returned goods before processing. |
| **Railway Infrastructure** | **Infraestrutura Ferroviária** | Physical components including tracks and facilities. |
| **Railway Network** | **Rede Ferroviária** | Complete system of interconnected railway lines. |
| **Refrigerated Car** | **Vagão Frigorífico** | Temperature-controlled wagon for perishable goods. |
| **Returns** | **Devoluções** | Products sent back requiring inspection and quarantine. |
| **Rolling Stock** | **Material Circulante** | All railway vehicles including locomotives and wagons. |
| **Route** | **Rota** | Ordered facility sequence train passes through. |
| **Scheduling** | **Calendarização** | Planning train movements to avoid conflicts and maximize efficiency. |
| **Siding** | **Desvio** | Designated crossing area on single-track segments. |
| **Simple Route** | **Rota Simples** | Route consisting of a single freight transport. |
| **Single Track** | **Via Simples** | Railway segment with one track requiring sidings. |
| **SKU (Stock Keeping Unit)** | **SKU** | Unique code identifying specific product type in inventory. |
| **Sorting** | **Triagem** | Process organizing wagons in freight yards for efficiency. |
| **Station** | **Estação** | Nodal point in railway network for logistical operations. |
| **Station Category** | **Categoria de Estação** | Classification grouping stations based on operational relevance (e.g., city, airport, main). |
| **Station Master** | **Chefe de Estação** | User overseeing facility operations and coordination. |
| **Station Storage Manager** | **Gestor de Armazenamento** | User responsible for warehouse operations. |
| **Tank Car** | **Vagão-tanque** | Wagon for liquids, chemicals, and fuels. |
| **Tare** | **Tara** | Empty wagon weight used in payload calculations. |
| **Terminal** | **Terminal** | Major railway facility for cargo handling and storage. |
| **Train Driver** | **Maquinista** | User operating trains and ensuring safe movement. |
| **Train Operating Company** | **Empresa Operadora** | Entity owning rolling stock and providing services. |
| **Unloading Dock** | **Doca de Descarga** | Warehouse access points where wagons are unloaded. |
| **Unloading Operation** | **Operação de Descarga** | Process removing cargo from wagons for storage. |
| **Wagon** | **Vagão** | Rail vehicle for freight transport with type-specific characteristics. |
| **Warehouse** | **Armazém** | Facility organized in aisles and bays for product storage. |
| **Warehousing** | **Armazenagem** | Storage of cargo at freight yards, terminals, and sidings. |
| **Acceleration** | **Aceleração** | Locomotive capacity to increase speed, important for calculating travel times and train performance. |
| **Arrival Time** | **Hora de Chegada** | Recorded instant when train crosses or arrives at an endpoint during route execution. |
| **Building** | **Edifício** | Physical structure within facility serving specific purpose (warehouse, grain silo, refrigerated area). |
| **Coupling** | **Acoplamento** | Operation of connecting locomotives and wagons together to form trains. |
| **Decoupling** | **Desacoplamento** | Operation of separating wagons from train when freight arrives at destination for unloading. |
| **Departure Time** | **Hora de Partida** | Recorded instant when train leaves an endpoint after stopping during route execution. |
| **Destination** | **Destino** | Final endpoint facility where freight wagons arrive and are unloaded. |
| **Diesel Locomotive** | **Locomotiva Diesel** | Locomotive powered by internal combustion diesel engine with specified fuel capacity. |
| **Dimensions** | **Dimensões** | Physical measurements of rolling stock including length, width, and height in millimeters. |
| **Distribution Center** | **Centro de Distribuição** | Facility connecting railway network with regional delivery and distribution networks. |
| **Electric Locomotive** | **Locomotiva Elétrica** | Locomotive powered by electricity from overhead lines with voltage and frequency specifications. |
| **Electrified Segment** | **Segmento Eletrificado** | Line segment equipped with overhead electrical systems allowing electric locomotive circulation. |
| **Entry Year** | **Ano de Entrada em Serviço** | Calendar year when specific locomotive or wagon was commissioned for operational service. |
| **Frequency** | **Frequência** | Electric current frequency specification for electric locomotives measured in Hertz. |
| **Fuel Capacity** | **Capacidade de Combustível** | Maximum diesel fuel storage capacity in locomotive tanks measured in liters. |
| **Grain Silo** | **Silo de Cereais** | Specialized vertical storage structure for bulk grain commodities at terminal facilities. |
| **High Cube Container** | **Contentor High Cube** | Taller container variant with 9.5ft internal height versus standard 8.5ft containers. |
| **Industrial Hub** | **Centro Industrial** | Facility or depot connecting railway network with manufacturing and production zones. |
| **Industrial Zone** | **Zona Industrial** | Geographic area with concentrated manufacturing facilities served by railway connections. |
| **Line** | **Linha** | Continuous railway connection between two endpoint facilities composed of multiple segments. |
| **Locomotive Model** | **Modelo de Locomotiva** | Technical specification defining locomotive family: make, power, acceleration, dimensions, weight. |
| **Make** | **Fabricante** | Manufacturer or brand name of locomotive or wagon model. |
| **Maximum Speed** | **Velocidade Máxima** | Highest permitted operational speed for rolling stock measured in kilometers per hour. |
| **Maximum Train Length** | **Comprimento Máximo do Comboio** | Predefined limit in meters restricting total length of coupled locomotives and wagons. |
| **Maximum Weight** | **Peso Máximo** | Total weight limit for locomotive or maximum load capacity per meter for line segments. |
| **Model** | **Modelo** | Technical designation identifying specific type of locomotive or wagon with shared characteristics. |
| **Multi-Gauge Support** | **Suporte Multi-Bitola** | Capability of locomotive or wagon to operate on multiple different gauge widths. |
| **Origin** | **Origem** | Initial endpoint facility where freight wagons are loaded before transport. |
| **Payload** | **Carga Útil** | Maximum weight of goods that wagon can transport, excluding the tare weight. |
| **Port** | **Porto** | Maritime facility with railway connections enabling container transfer between ships and trains. |
| **Power** | **Potência** | Locomotive engine power output measured in kilowatts, determining pulling capacity. |
| **Quad Track** | **Via Quádrupla** | Railway segment with four parallel tracks enabling very high capacity operations. |
| **Received At** | **Recebido em** | ISO timestamp recording exact moment when product box arrived at warehouse. |
| **Refrigerated Area** | **Área Refrigerada** | Temperature-controlled storage building at facilities for perishable goods. |
| **Regular Container** | **Contentor Regular** | Standard height container with 8.5ft internal height in 20ft, 40ft, or 45ft lengths. |
| **Speed Limit** | **Limite de Velocidade** | Maximum permitted train speed on specific line segment measured in km/h. |
| **Stacked Container** | **Contentor Empilhável** | Container type not supported in European railways due to overhead electric lines and tunnels. |
| **Supply Chain** | **Cadeia de Abastecimento** | Complete logistics process from origin to destination including transport, storage, and handling. |
| **Timetable** | **Horário** | Schedule specifying planned times for train departures, arrivals, and passage at facilities. |
| **Train Composition** | **Composição do Comboio** | Specific arrangement of locomotives and wagons forming complete operational train unit. |
| **Type** | **Tipo** | Classification category for wagons based on transported goods or locomotive power source. |
| **Voltage** | **Voltagem** | Electric supply voltage specification for electric locomotives measured in volts. |
| **Volume Capacity** | **Capacidade Volumétrica** | Maximum internal volume of goods that wagon can contain measured in cubic meters. |
| **Wagon Model** | **Modelo de Vagão** | Technical specification defining wagon family: type, dimensions, payload, volume capacity. |
| **Wagon Type** | **Tipo de Vagão** | Classification based on goods transported: boxcar, flatcar, tank car, hopper car, refrigerated car. |
| **Weight on Track** | **Peso na Via** | Calculated load distribution on rails: total weight divided by number of wheels on track. |
| **Allocation** | **Alocação** | Process of assigning specific quantities from warehouse boxes to fulfill customer order lines, creating a picking plan. |
| **Backbone Network** | **Rede de Espinha Dorsal** | Minimal set of railway tracks required to connect all stations in a network, used for cost estimation and planning. |
| **Crossing** | **Cruzamento** | Operational maneuver where trains pass each other on single-track segments using sidings or stations. |
| **Picking Plan** | **Plano de Picking** | Plan that organizes items to be collected from the warehouse into trolley runs, respecting weight capacity. |
| **Throughput** | **Capacidade de Processamento / Débito** | Maximum flow of trains (or cargo volume) that can pass through a corridor or between two hubs per unit of time. |
